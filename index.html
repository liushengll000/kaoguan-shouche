② 关于树牢正确权力观、政绩观、事业观论述

PDF · 2026.01 · 习近平总书记重要论述汇编
▾

前言关键引用："树立和践行正确的政绩观，起决定性作用的是党性。""共产党人必须牢记，为民造福是最大政绩。""新征程是充满光荣和梦想的远征，没有捷径，唯有奋斗。"

一、重大意义

  • （一）从历史看：党的优良传统。毛泽东"全心全意为人民服务"；邓小平"帮助人民群众自己动手"；新时代"以人民为中心"，"人民对美好生活的向往就是我们的奋斗目标"。
  • （二）从现实看：①巩固党的执政地位、完成执政使命的内在要求——"把抓好党建作为最大的政绩"。②践行以人民为中心的具体体现——"为民造福是最大政绩"。③营造风清气正政治生态的必然要求。
  • 理论维度：马克思主义权力观政绩观事业观在新时代的生动实践；实践层面：推动高质量发展的必然要求；长远：关乎执政根基与长治久安。

二、丰富内涵及内在联系

1. 正确权力观

  • 回答四个核心问题：权力为何物、权力为何授、权力为何用、权力依何行。
  • 权力为何物：本质是公共资源和责任载体，社会主义中国权力本质属性是人民性，"我们的权力是党和人民赋予的，是为党和人民做事用的"。
  • 权力为何授：人民对执政者的信任与委托；宪法"一切权力属于人民"。认知错位→行为失向（"不怕群众不满意，只怕领导不注意"）。
  • 权力为何用：服务于公共利益与治理目标，需以"正当性"为前提，符合法律规定。"立党为公、执政为民"。
  • 权力依何行：依法依规是基本准则。"公正用权、依法用权、为民用权、廉洁用权"；"有权必有责、用权受监督、违法必追究"。

2. 正确政绩观

  • 回答：政绩为谁而树、树什么样的政绩、靠什么树政绩。
  • 为谁而树：为人民而树，"为民办事、为民造福是最重要的政绩"。
  • 树什么样的政绩：经得起实践、人民、历史检验；不是短期形象工程，是惠及群众的实绩。例：塞罕坝荒漠变林海。
  • 靠什么树政绩：靠真抓实干、勇于担当、廉洁奉公。

3. 正确事业观

  • 核心内涵：坚持党的事业第一、坚守人民利益第一、服从工作需要第一。
  • 例：黄文秀（广西百色百坭村第一书记）——以人民为中心的事业。
  • 怎么样干事业：真负责、勇担当、敢斗争。

内在联系

权力观为政绩观和事业观提供价值导向；政绩观是权力观的实践载体和事业观的具体体现；事业观为前两者注入精神动力。

三、实践要求——处理好"五个关系"

  • ①党性与个性：强化党性锤炼，"党性是立身立业立言立德的基石"，"理想信念是精神上的钙"。
  • ②对上与对下：强化为民思想，"民之所盼、我必行之"。
  • ③潜绩与显绩：强化实干担当，"为官一任、造福一方"；"功成不必在我"，甘于做铺垫性工作。例：红旗渠、谷文昌。
  • ④干事与成事：强化本领养成，"领导干部不仅要有担当的宽肩膀，还得有成事的真本领"。
  • ⑤自律与他律：强化制约监督，"习惯在受监督和约束的环境中工作生活"。

结语："权力因人民赋予而神圣，政绩因为民造福而闪耀，事业因与党和人民同频共振而不朽。"

③ "十五五"时期山东经济发展形势与发展动力

PDF · 提纲 · 约122页 · 经济形势与发展动力
▾

总览

  • 习近平总书记赋予山东"走在前、挑大梁"重大使命。
  • 2025年山东GDP达10.3万亿元，全国第三个、北方第一个迈入"十万亿俱乐部"省份。
  • 目标：加快建设绿色低碳高质量发展先行区，打造高水平对外开放新高地，努力成为北方地区经济重要增长极。

一、"十四五"成就（发展基础坚实）

  • GDP增长5.5%、达10.3万亿；粮食总产稳定在1100亿斤以上；民营经济增加值增长31.6%。
  • 三次产业结构 6.6 : 39.3 : 54.1（"三二一"）。
  • 19条标志性产业链；制造业总体规模全国第一梯队；国家制造业单项冠军274家、专精特新"小巨人"1356家；国家级数字领航企业18家、工业互联网平台46家（均居全国首位）。
  • 高新技术企业5年增加2万多家；发明专利授权累计26.2万件（翻番）。
  • 非化石能源发电装机达1.39亿千瓦，占比提升至54%，历史性超过煤电；空气优良天数比例77.8%。
  • 沿海港口货物吞吐量超21亿吨居全国首位；算力规模增长3.5倍，智能算力占比超50%。
  • 常住人口城镇化率67.5%；城乡收入比缩小至2.12；人均预期寿命80.5岁。
  • 文化："好客山东 好品山东"品牌；国际孔子文化节、尼山世界文明论坛。

结构性矛盾（挑战）

  • 政策周期"拐点"明显（重化工业特征）；低端产能过剩、高端核心技术缺乏；人口红利"黄金增长期"逐渐失却；区域差距（东西部）；资源结构优势发挥不足（人力资源未转人力资本，质量竞争力指数全国第10）；文化资源认识不足。

二、宏观环境

  • 国际：世界百年变局加速，单边主义保护主义抬头，关税战贸易战冲击；中美博弈复杂。王毅（2026.3.8）：相处之道"相互尊重、和平共处、合作共赢"；2026是中美关系"大年"。
  • 特朗普2026年5月13-15日访华，两国元首同意将"中美建设性战略稳定关系"作为新定位。
  • 国内：制度优势、大国优势、超大规模市场需求优势（14亿+人口、4亿+中等收入群体）、经济综合优势、文明理念优势。
  • 中国GDP 2025年达140万亿元稳居世界第二，占世界经济18%，对世界增长贡献超30%；占美国经济约70%。
  • 世界500强中国130家；独角兽全球1523家（美国758、中国343，中美占72.2%）；瞪羚羊中国278家。
  • 中国R&D研发费用2025年3.9万亿，占全球超20%仅次于美国；全球创新指数排名从2020年第14位跃升至2025年第10位。
  • 五年规划是中国特色制度优势（陈云、周恩来等先后说明"一五"至"七五"）。

三、发展动力剖析

  • "十五五"GDP年均增速设定5%（工作中全力争取更好），经济大省必须"挑大梁"。
  • （一）科技创新是发展新质生产力的核心要素：强平台（崂山实验室、争创国家区域科技创新中心、济南"激光谷"近300家激光企业）、强主体（企业站C位，"科工一体"，天润工业创新联合体）、强转化（山东科技大市场、职务成果单列管理）。
  • （二）产业转型升级：制造业是山东"脊梁"；新兴产业扩容（高端装备、信息技术产值过万亿，布局50个特色集群）；未来产业（量子、生物制造、深海极地，济青烟3个先导区+20条政策）；数字经济赋能（"人工智能+"、山钢智慧炼钢、济南工业软件中试基地）。
  • （三）扩大内需：户籍常住人口"双过亿"，2025社零总额4.2万亿；以旧换新、服务消费（服务业增加值约5.59万亿、贡献率近六成）、有效投资。
  • （四）绿色转型："十五五"是碳达峰决胜期；2025非化石能源装机占比54.2%超煤电；光伏装机连续8年全国第一；核电核准在建全国第三。
  • （五）开放赋能：上合示范区、自贸试验区、跨国公司领导人青岛峰会；"一国一策"；"鲁贸全球""好品山东"。

四、政策建议

  • 锚定"走在前、挑大梁"，实施"十大工程"、塑强"十个新优势"；陆海统筹发挥海洋优势（海岸线3345公里占1/6）。

四、停电查询方法（重点·四种方法）

方法1：依据停电事件查询 ｜ 方法2：依据曲线查询 ｜ 方法3：透抄电能表内数据 ｜ 方法4：依据停电监测查询

方法1：依据停电事件查询

  • 路径：新一代 数据批量查询 → 事件数据查询 → 终端事件（终端停上电）/ 电能表事件（电能表掉电）。
  • 事件类型与时限（举例）：电能表 OI:3011 主动上报给终端，停电发生10分钟内上报；电表模块 OI:3011 主动上报给终端（不带时间）；采集终端 OI:3106 主动上报给主站，停电发生时间/上次复电时间，10分钟内上报。
  • 优点：信息准确；缺点：不明朗。

方法2：依据曲线查询

  • 路径：数据批量查询 → 曲线数据批量查询 → 电压/电流/功率/电能示值曲线。
  • 判断特征：电压/电流/功率 空值或0 → 可能存在采集缺点；电能示值 空值或示数不变。
  • 需结合电能表停电事件综合判断。
  • 优点：简单明了；缺点：信息不准。

方法3：透抄电能表内数据

  • 路径：电能表数据召测 → 电能表明细。

方法4：依据停电监测查询（推荐·功能最全）

  • 路径：拓展应用 → 停电监测。
  • 子功能：实时停电查询、历史停电查询、停电统计、重点用户监测、民生用户监测、停电时长监测、停电趋势分析、回溯功能。
  • 停电全景监测：短时停电监测、频繁停电监测、灾害监测。

⑤ 供电服务关键风险点辨识与防范

结构

第一部分（背景案例）｜ 第二部分 客户服务典型应用场景（12类诉求）｜ 第三部分 事前风险防范

第一部分 · 背景案例

  • 案例：2025年6月泰安市气象局发布当年首个高温红色预警（一周内气温攀升至40℃以上）。
  • 泰安公司客户服务专项稽查：营销稽查监控中心梳理上半年电压质量问题工单，对15条未改善工单发设备管理单位落实整改。
  • 向其他专业发布《业务联系单》提醒；电压质量问题"威胁电网安全、影响用电感知、治理周期长"。

第二部分 · 供电服务高频诉求（12类客户诉求）

  • 诉求01 电量电费异常：14个细分场景（阶梯电价升档、增加用电人口、新增大功率设备、客户侧漏电、季节性、非直供、老人孩子居住、尖峰电量多、功率因数不达标加收、电能表失准、错接线、换表录错表码、采集表码突变、长期不在家突然收到电费通知）。四步法：共同计算合理电量、检查公司设备、协助用能诊断、电能表校验。
  • 诉求02 非直供电小区要求转直供：转供加价过高、小区配网差频繁停电、移交改造方案不合理。
  • 诉求03 交费差错更正：场景一不小心交错（同时校验户名户号+弹窗提醒）；场景二故意错交/洗钱（洗钱风险：分拆缴纳至个人户号再退费/销户；电信诈骗诱导转账）。标准话术见下。
  • 诉求04 错发短信：档案联系方式错误、变更未及时更新、客户拉黑未订阅。网格服务事前告知、营销上行短信统计、与运营商信息共享。
  • 诉求05 电器损坏核损。
  • 诉求06 电价执行错误：新装方案错误（内外勾结/营业差错）、私自改变用电性质、对政策不认可。电价自动校正。
  • 诉求07 增加客户办电成本：表前线让"三零"客户承担、施工单位私收表箱费、农灌表后线过长、未预留充电桩位置。
  • 诉求08 对催费方式有异议：欠费停电前未通知、未收到短信、催费时间不合理/频繁、态度差、垫付后催费、不知情改费控、不认可张贴通知单、非直管小区欠费不能停电？
  • 诉求09 私自更名过户：更名与过户混淆、长期不用电户名被改、产权纠纷未过户（案例：2019年更名不规范投诉、8月过户未通知投诉→舆情）。

一、AI发展历程与概念

  • 定义：AI是利用计算机模拟人类智能行为科学的统称（会听、会看、会说、会思考、会学习、会行动）。
  • 图灵测试：1950年图灵《计算机与智能》；"人工智能之父"麦卡锡（1956达特茅斯会议正式命名）。GPT-4.5（2025.4）人类误判率73%；MiniMax国内首个通过人机辩论图灵测试（骗过42%观众）。
  • 里程碑：1966第一次AI寒冬；1980专家系统（XCON每年省数千万）；1997深蓝胜卡斯帕罗夫；2016 AlphaGo 4:1胜李世石；2022.11.30 ChatGPT引爆大模型；2024.10 Hinton（深度学习之父）获诺贝尔物理学奖。
  • DeepSeek：2025.1.20发布R1（性能对标GPT-4，训练成本仅1/10）；梁文锋（1985，广东）。Manus（肖弘，1993）2025.3.6发布；2026发改委禁止Meta收购Manus。
  • 2026多"元年"：智能体AI元年、世界模型元年、具身智能落地元年。
  • 中国AI：2024.3"人工智能+"写入政府工作报告；2025.8《关于深入实施"人工智能+"行动的意见》（国发〔2025〕11号）；2024我国AI产业规模超9000亿（+24%），2025核心产业超1.2万亿，2026预测破1.5万亿；企业超6000家（全球15%）。
  • 山东AI：骨干企业1124家，核心产业营收破1200亿（占全国10%）。泰安：华鲲振宇北方基地（肥城）97天投产，年产7万台AI一体机；规上工业企业关键业务数字化率76.82%、转型覆盖率95.1%。

核心概念

  • 机器学习：核心不是写规则，而是从数据自动找规律（泛化能力）；过程：收集清洗→特征→选模型→训练→验证→部署。
  • 深度学习：原始数据→多层可学习表示→输出（端到端）。核心：强算力+海量数据+先进模型。框架：TensorFlow、PyTorch、Caffe（贾扬清）。
  • CNN（空间）/ RNN（时间）/ Transformer（全局关系，注意力机制，NLP核心）。
  • 大模型："大"=参数庞大+数据量大+算力高。GPT-3（1750亿）→GPT-4（1.8万亿）→GPT-5.5（约9万亿，2026.4）。DeepSeek-V3（671B混合专家）；V4总参数1.6万亿、100万token上下文。
  • 多模态大模型（MLLM）：文本/图像/音频/视频联合训练，具身智能"大脑"。
  • AIGC：继PGC、UGC之后的第三代内容创作方式。
  • 大模型分级：L0通用（通识教育）、L1行业、L2垂直/任务。
  • 光明电力大模型：国家电网发布，国内首个千亿级多模态电力行业大模型（2024.12.19北京发布，"光明"配网调度员亮相）。
  • 世界模型：感知编码→动态推演（当前+动作→未来）→控制决策；强调"可解释！"。应用：自动驾驶（特斯拉、蔚来NWM）、机器人、科研仿真。
  • 具身智能：1950图灵提出；2025/2026政府工作报告连续提及培育；2026.6.1行业标准YD/T 6770实施。
  • AI发展阶段比喻：聊天机器人→推理者（DeepSeek-R1）→代理者（OpenClaw）→创新者（2030后）→组织者（2040后）。

  • AI+电力场景：①负荷预测与平衡（国电南瑞）②故障诊断与预测性维护（提前24-72h预警，误报率降40%）③新能源消纳与零碳（远景、阳光电源）④智能运维与安全管控（特变电工鲁缆无人质检年省300万）⑤数字化管理与决策。
  • 挑战：技术（单点局部应用、缺全链条通用模型、可解释性不足）；管理（数据孤岛）；"十五五"双重压力（增量提速+电价市场化）；风险管控与规则空白。
  • 行业大模型：长城（中国石化，推理效率+100%）、昆仑（中国石油，3000亿参数）、海能（中国海油）。

PART 4：AI工具应用——从提示词到自主闭环

  • AI编程工具：零代码一句话生成逻辑（班组个性化、临时定制）；对比普通智能体（低代码模板）更灵活。

  • 工具箱建设：内网AI助手Agent引擎（IM入口）、技能商城、V1.0.7版本。
  • 结语：2026董事长要求AI全员化、工具化；立足岗位熟练运用，将AI转化为岗位实践成果。
